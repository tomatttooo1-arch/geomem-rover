# "约 2.4 个处理器核"的算式

含义：如果把 PL 承担的计算全部改由 A53 软件完成，按产品帧率需要的 A53 核数 = 每项单核耗时 ÷ 该项的帧间隔，逐项相加。
深度链各项（几何、融合、代价图）按相机深度帧 30 帧/秒，帧间隔 33.3 ms；识别链各项（前处理、后处理、深度核验）按整机识别帧率 7.11 帧/秒，帧间隔 1 ÷ 7.11 = 140.6 ms。

| 项 | A53 单核耗时 | 帧间隔 | 核数 | 出处（包内） |
|---|---|---|---|---|
| 几何换算（定点，PL 同算法） | 56.1 ms | 33.3 ms | 1.685 | `a53_baseline/a53_bench_results.md` L7，geo_fx 行，单核中位 56.140 ms |
| 融合 | 0.414 ms | 33.3 ms | 0.012 | `a53_baseline/a53_bench_results.md` L25，fuse_r10 integrate 组中位 0.414 ms |
| 代价图 | 0.470 ms | 33.3 ms | 0.014 | `a53_baseline/a53_bench_results.md` L11，grid_formal 行，单核中位 0.470 ms |
| 图像前处理 | 18.3 ms | 140.6 ms | 0.130 | `a53_baseline/a53_prep_post_note.txt` L1、L7（软件前处理 18.3 ms/帧） |
| 识别后处理 | 6.70 ms | 140.6 ms | 0.048 | `a53_baseline/a53_prep_post_note.txt` L1、L8（CPU 后处理 6.70 ms/帧） |
| 深度核验（19 框一帧） | 70.3 ms | 140.6 ms | 0.500 | `a53_baseline/a53_bench_results.md` L12，roi19 行，单核中位 70.289 ms |
| 合计 | | | **2.39 ≈ 2.4** | |

算式：56.1/33.3 ＋ 0.414/33.3 ＋ 0.470/33.3 ＋ 18.3/140.6 ＋ 6.70/140.6 ＋ 70.3/140.6 = 1.685 ＋ 0.012 ＋ 0.014 ＋ 0.130 ＋ 0.048 ＋ 0.500 = 2.39。
识别帧率 7.11 帧/秒的出处：`golive_m7/chain_report.txt`。

口径说明：各项都是单核中位耗时（单实例绑一个核，只计软件参照函数本身的墙钟时间，见 `a53_bench_results.md` L3）；代价图一项取 grid_formal 行的每条记录中位（该轨迹含融合与代价图各类操作），其中单看代价图操作一组的中位为 1.307 ms（同文件 L30）；没有计入规划、记忆、搜索三个核的软件耗时，也没有计入 DPU 推理本身。
