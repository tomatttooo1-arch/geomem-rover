# 整板 LUT 演进：85,747（73.2%）→ 40,895（34.9%）

两份都是 Vivado 2022.2 布线后的整板分层资源报告（report_utilization -hierarchical），器件 xck26-sfvc784-2LV-c，LUT 总量 117,120。
文件里只保留了资源表本身（原样摘行），报告头里的主机名与目录已去掉。

| 文件 | 比特流 | 整板 LUT | 占比 |
|---|---|---|---|
| `util_hier_v3fc2_142.txt` | v3fc2 整板（提交 3c087c9，快钟 142.86 MHz 档），2026-10-26 | 85,747 | 85,747 ÷ 117,120 = 73.2% |
| `util_hier_m4_166.txt` | m4 整板（快钟 166.67 MHz 档，构建号 0x08880589），2026-11-03 | 40,895 | 40,895 ÷ 117,120 = 34.9% |

两份比特流装的是同一组功能：几何帧核（frame）、融合与代价图核（rolling）、深度核验核（roi）、行驶许可核（permit）及系统信息、时基；两份都不含 DPU，也不含后来加入的规划、记忆、搜索、前后处理核。
产品整板比特流（`bitstream_m7_fullboard/`）在 m4 之后装入了这些核，整板 LUT 为 89,426（76.4%），见该目录的分层报告。

## 两者差在哪（按分层报告逐实例相减，单位 LUT）

| 实例 | v3fc2 | m4 | 变化 | 说明 |
|---|---|---|---|---|
| ar（车屏叠加核） | 21,398 | — | −21,398 | m4 中删除，车屏叠加不再放在 PL |
| sc_mem2（车屏核的访存互连） | 2,261 | — | −2,261 | 随车屏核一起删除 |
| frame（几何帧核） | 38,936 | 24,638 | −14,298 | 几何核瘦身 |
| roi（深度核验核） | 10,009 | 6,268 | −3,741 | 核验核瘦身 |
| rolling（融合与代价图核） | 9,517 | 8,376 | −1,141 | 融合核瘦身 |
| sc_mem0 / sc_mem1 / sc_mem3（访存互连） | 761 / 374 / 761 | — | −1,896 | m4 分层报告中不再有这三个互连实例 |
| sc_ctrl（控制口互连） | 1,245 | 1,112 | −133 | |
| rst_pl1 | 16 | 13 | −3 | |
| permit、sysinfo、timebase、rst_pl0 | 395、78、1、16 | 同左 | 0 | |

合计减少 44,852 LUT（85,747 − 40,895）。其中删除车屏叠加核及其互连 23,659 LUT（约 53%），三个计算核瘦身 19,180 LUT（约 43%），其余互连 2,032 LUT。
（各实例相加分别为 85,768 与 40,897，比顶层多 21 与 2，是分层报告的计数口径差，报告末尾的注释说明了这一点。）
