## 背景（owner 11-03 20:1x 定）
几何核（fpga_m7_frame_axi，m4 整板约 24,600 LUT / 151 DSP / 27 BRAM）的大头是换算级（约 11,800 LUT / 136 DSP）：当初照 CPU float32 代码、按"与 CPU 逐位一致"做成每像素一整套 IEEE 浮点（15 fadd、18 fmul、3 个双精度减法、两组 54×27 级大乘）。owner 定：**改成定点重设计，去掉几何核冗余**；新规矩：**先出硬件设计、经主控审过再用 HLS 实现**，软件参考只作黄金模型。

## 第一阶段要交（RUN/GEO_FX0/DESIGN.md，交主控审；审过才进第二阶段写 HLS）
1. **算法重述**：几何核从深度码到体素占据/射线行走输入的完整数学（内参、外参、depth_unit、相机/世界/格坐标、量化到 Q8、原点、射线端点、抽稀、越界判定），哪些量每帧常数（由 PS 预算下发）、哪些逐像素。
2. **定点架构**：结构框图；每级运算、位宽（整数位/小数位）与舍入方式、每级误差上界推导（到体素 0.05 m 与 Q8 的尺度）；乘法器映射到 DSP48E2（27×18）的方案与个数；每列/每行系数表放 BRAM/LUTRAM 还是寄存器；流水级数、II=1；与行走级接口（射线记录格式，尽量不变，变则写清）；原点/一帧一次的量（double 减法、q8 串行步）改为 PS 下发或多拍串行。
3. **输入路径决策**：建议只保留 16 位深度码输入（相机原生），去掉 float 输入通路；写出对主机驱动/回放工具的影响与坏处，交主控定。寄存器映射只增不移。
4. **其余冗余**：AXI 主口 FIFO/突发参数、AXI-Lite 打包、清零/写回循环、8 路行走每路（约 700 对手算 500–600）——逐项给改法与预计，标"本次做/不做"。
5. **手算预算**：换算级与整核 LUT/FF/DSP/BRAM、拍数（每帧 rec30/TUM200/真相机），对照 m4 现值（GEO_SLIM4 ooc/m4g：25,421 LUT / 151 DSP，WNS +0.260  at 6 ns）。目标建议：换算级 ≤4k LUT、≤25 DSP；整核拍数不多于现版。
6. **定点黄金模型（C/C++，宿主）＋质量门**：实现与设计逐位一致的定点参考；在五组数据（rec30 310、tum200 200、car570 570、tum1209 1209、car1015 1229；射线抽稀开关 0/1）上与现 float 参考比较。质量门**测前写死**（建议：逐帧占据/空闲/未知体素一致率 ≥99.9%；障碍（占据）体素漏检 0 或 ≤万分之一且全部可归因于边界舍入；B1 代价图致命格不丢；GRID/融合下游一帧积分后一致率同上），先写判据再跑；附阳性对照（故意加大舍入误差一档必须被门抓住）。
7. 坏处清单：不再与 CPU float 参考逐位一致、回放工具与文档里"逐位"表述的改法、需重测的文档数。
