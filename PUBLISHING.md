# GitHub release snapshot

This repository is the final competition release of Shiyi (拾忆), an FPGA-centric object-finding robot with semantic spatial memory, dated 2026-11-04. It is identical in content to the submitted source package `fpga_submit_code.rar`.

Deployment scripts use the generic account `robot`; configure your own SSH aliases, directories and credentials locally before running them. Model files and bitstream packages are release assets; their checksums and third-party notices are included (`SHA256SUMS`, `THIRD_PARTY_NOTICES.md`). `RELEASE_SHA256SUMS` lists every file in this snapshot.
