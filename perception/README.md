# perception/ —— 感知与语义空间记忆

作品的算法主体：几何语义空间记忆的建立与维护、实例关联（同一个物体跨帧跨次是不是同一个）、
检索算法（"我的钥匙在哪"→ 位置），以及每个算法对应的 **CPU 黄金模型**。

黄金模型是硬件加速的对照基准：先有能跑对的 CPU 版本，再谈把哪一段搬到 PL 上，
以及搬完之后结果是否一致。没有黄金模型的加速没法验收。

这里的代码原则上不依赖板子，主机上就能跑、就能测（单测放 `tests/`）。
