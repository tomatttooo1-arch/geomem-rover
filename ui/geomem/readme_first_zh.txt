GeoMem M8 · 智能寻物小车界面演示包
版本：2026-10-15 / Windows x64

一、怎么打开
1. 先把整个 ZIP 压缩包解压到一个文件夹，不要在压缩包内部直接运行。
2. 双击“start_demo.cmd”。浏览器会自动打开界面。
3. 保留启动窗口；关闭窗口或按 Ctrl+C 即可结束服务。

无需安装 Node.js、Codex、Python 或开发工具；不需要管理员权限。
建议使用 Windows 10/11 64 位和新版 Edge / Chrome。
运行环境已附带，首次演示也不需要联网。Mac/Linux 不适用本启动器。
如果浏览器没有自动打开，复制启动窗口中的地址手动访问。
默认地址为 http://127.0.0.1:8788；端口被占用会自动顺延，以窗口显示为准。

二、建议体验顺序（约一分钟）
1. 查看三维房间：拖动旋转，滚轮缩放，切换“全局记忆 / 局部三维”。
2. 点击“书包”，再点“查找物品”。在详情中点击“开始寻物”。
3. 观察任务进度、小车移动；试试暂停、继续、停止。
4. 在左侧切换空间记忆、任务记录、设备与连接，查看界面过渡。
5. 试试按钮的悬浮和按压反馈，或通过右上角设置查看连接配置。

三、这是什么版本
这是 M8 用户交互前端演示包。地图、物体位置和小车运动默认来自模拟数据。
可以体验完整交互，但不能据此证明实车已经完成识别、导航或寻物。
真实模式连本机桥接服务（bridge/geomem_bridge.py，协议第二版，见 docs/PROTOCOL_V2_DESIGN.md §2）；桥托管页面时打开 http://127.0.0.1:8788/?source=live 即直接连车。“vehicle_interface_protocol.md”是已作废的 v1。

四、给队友的文件
app/：当前前端源代码、Three.js 资源和本地静态服务，可直接编辑。
runtime/：随包提供的 Node.js Windows x64 运行环境及完整许可证。
start.mjs：便携启动器，自动选择端口并打开浏览器。
vehicle_interface_protocol.md：后端对接文档。
界面预览.png：界面静态预览，无法运行时也能先看外观。

五、常见问题
• 请用启动器打开，不要双击 app/index.html。
• 看不到三维画面或明显卡顿：检查浏览器硬件加速，并使用新版 Edge / Chrome。
• 浏览器开启“减少动态效果”时，界面会按系统偏好关闭大幅动画。
• 任务记录保存在当前电脑浏览器中，不随 ZIP 传给别人。
• 127.0.0.1 地址只属于运行该包的电脑；给其他人分享时请发送 ZIP。
• 启动器仅监听本机回环地址，不会自动把服务开放到局域网或互联网。
