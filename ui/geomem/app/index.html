    物品详情

    小车按类别查找：记忆里有多个时会请你选择具体哪一个。

    小车会前往物品附近的观察点并重新观测确认。记忆位置不代表物品仍在原处。

    数据源与连接

    演示模式无需设备；实车模式需要团队部署 M8 桥接服务。

    使用 GeoMem 第二版协议，连接本机桥接服务（默认与页面同源的 /ws）。不是直接连接车上的 hub 或 rosbridge。

    让寻找更简单

    1. 看看空间

      全局记忆查看房间、物品和路径；局部三维跟随小车查看附近点云。

    2. 找到目标

      输入物品名称后点「让小车找」，或在物品卡片里点「寻找这类物品」。小车按名称查找；记忆里有多个同类物品时，任务卡会列出候选，请点选具体哪一个。

    3. 确认后出发

      检查上次见到的时间与位置，再开始寻物。任务会展示检索、行驶、现场确认的进度；随时可以停止。

    快捷键：/ 聚焦查找；Esc 关闭弹窗。地图支持触摸旋转和双指缩放。演示中的点云、识别分数和任务结果均为模拟值。
