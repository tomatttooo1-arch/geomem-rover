# GeoMem M8 产品事实

更新于 2026-10-14。仅记录用户明确需求及当前代码事实，不代表实车验收或用户研究结论。

## 产品与任务

这是“基于几何语义空间记忆的智能寻物小车”的 M8 用户交互 Web/PWA 前端。核心操作是查看全局空间记忆与局部三维点云，检索和选择物品实例，发起寻物，查看任务进度，以及暂停、继续或请求停止任务。已有空间记忆、任务记录、设备信息和数据源设置页面。

## 已确认使用约束

用户要求优先按电脑屏幕比例设计，主要考虑 1920×1080 和 1440×900；手机属于兼容布局。用户明确选择明亮的透明玻璃、3D 科技感、立体和实物感觉，并要求每个界面切换自然流畅、有流动感。视觉实现和运动规范以 [docs/DESIGN.md](docs/DESIGN.md) 为准。没有已提供的访谈、用户画像或品牌研究。

## 当前边界


界面不实现导航、避障或底盘速度控制。软件“停止任务”是取消请求；ACK 表示受理，不证明机器人已停止。连接失效或数据过期时显示未知状态并限制新任务，不自动重发控制请求。

## 技术与交付

采用本地 Web/PWA、原生 JavaScript、CSS、Three.js；静态资源已本地保存，不依赖外部字体或图片生成 API。通过本地 HTTP 服务运行，当前入口为 `http://127.0.0.1:8788`。PWA 安装与离线能力取决于浏览器和安全上下文；实车接入契约见 [docs/protocol.md](docs/protocol.md)，实际测试与限制见 [docs/VALIDATION.md](docs/VALIDATION.md)。
