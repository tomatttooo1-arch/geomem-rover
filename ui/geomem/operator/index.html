    物品详情

    小车将前往物品附近的可达停靠点，并重新观测确认。记忆位置不代表物品仍在原处。

    数据源与连接

    当前网站直接显示真实相机；比赛指令经过 v2 转发桥连接车栈。

    桥接服务运行在服务器上，负责连接 Nano 与底盘；不要把原始 rosbridge 地址直接填在这里。

    远程驾驶页的视频通过本机 SSH 通道自动接入；此处仅配置寻物地图的数据源。

    让寻找更简单

    1. 看看空间

      全局记忆查看房间、物品和路径；局部三维跟随小车查看附近点云。

    2. 找到目标

      输入物品名称，或点击物品卡片。有多个同名物品时，请先选择具体实例。

    3. 确认后出发

      检查最后观测时间与位置，再开始寻物。任务会展示检索、规划、行驶、现场确认的进度。

    快捷键：/ 聚焦查找；Esc 关闭弹窗。地图支持触摸旋转和双指缩放。演示中的点云、识别分数和任务结果均为模拟值。
