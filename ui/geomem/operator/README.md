
# GeoMem M8 用户交互界面

2026-10-19 当前入口：原网站 `http://127.0.0.1:8788/#remote`，默认真实连接，停用演示入口与旧 PWA 缓存。`src/remote-layout.css` 将原遥控页扩展为一屏比赛控制台；第一视角、第三视角与分屏，遥控、寻物、候选、撤销、结束建图常驻；连接、流程、日志、相对目标位于点开抽屉。控制统一走 v2 转发桥，旧 `/rover/drive` 已关闭。下文 10-14/10-18 内容仅为历史记录，不代表当前入口行为。现行接线、启动、测试边界见 `docs/COMPETITION-LIVE-20261019.md`。



## 启动和体验

给 Windows 队友直接体验：项目根目录 `交付/GeoMem-M8-Windows-x64-20261015.zip` 是自带 Node.js 的免安装包。解压后双击 `start_demo.cmd`，自动打开浏览器；默认端口占用时自动顺延。源码、预览图、使用说明和实车协议均在包中。演示无需联网或安装 Codex。打包源文件位于 `portable/`。

Windows 双击项目根目录的 `启动M8界面.cmd`，保持窗口开启，在 Edge/Chrome 打开 http://127.0.0.1:8788 。如果此地址已经运行，无需重复启动。关闭服务可在运行窗口按 Ctrl+C。

也可在本目录执行 `npm start` 或 `node server.mjs`，要求 Node.js 20+。前端依赖已本地保存，无需 npm install，不依赖外部字体、CDN 或图片 API。不要直接双击 index.html；ES 模块与 PWA 需要 HTTP 服务。

1. 默认进入明确标注的演示空间，可旋转缩放地图，切换全局记忆 / 局部三维。
2. 输入“书包”“鼠标”“水杯”，点击查找；也可点物品卡片或地图标签。
3. 在详情中核对物品实例、记忆坐标、最后观测时间，再点击开始寻物。
4. 体验检索 → 规划 → 行驶 → 现场确认。演示任务约 16 秒完成，可暂停、继续或停止。
5. 空间记忆页可筛选；任务记录页可查看本机最近 50 条终态记录并导出 JSON。
6. 数据源与连接中切换到实车模式，填写团队桥接服务地址。不能将原始 rosbridge 地址直接当作本项目的 M8 服务。

## 为什么选择 Web/PWA

当前 M8 的主要使用设备是电脑，需要可视化、键盘输入与团队演示。Web 可同时适配 Windows、手机和平板，更新集中，避免首版同时维护桌面/Android/iOS。已有 ROS/RViz2 可继续作为调试与数据核对工具。

用户原方案推荐 RViz2 + 简单面板；本版为了界面体验采用 Web，并使用现成的 Three.js 渲染器，不自研渲染引擎。协议隔离前端与 ROS：M4/M5/M6 后续通过服务提供快照与任务回执。原文件未修改。

PWA：首次联网打开后缓存应用资源；Edge/Chrome 在满足自身安装条件时可通过菜单安装。localhost 被视为安全上下文；手机通过局域网 HTTP 访问可用普通网页，但 PWA 安装/离线能力通常要求 HTTPS。移动端原生安装未做真机验收。

服务默认只监听 127.0.0.1，不对局域网开放。需要手机访问时，由部署者设置 `HOST=0.0.0.0` 并配置防火墙/HTTPS；不要将此演示静态服务直接暴露到公网。服务没有内建公网认证。

## 已实现

- 电脑优先的银白冰蓝玻璃界面，深蓝文字、透光层次和有厚度的边缘；三维空间采用倒角实体、环境反光与投影。主要适配 1920×1080、1440×900。页面淡化位移过渡、弹窗浮现、平滑视角和小车位姿插值；连续操作可打断动画，支持系统减少动态效果设置。
- 响应式中文工作台；桌面导航 / 手机底栏；键盘 / 查询快捷键、可关闭对话框、输入校验。
- Three.js 交互三维：示意房间、真实三维点云数据结构、机器人位姿、语义物体标签、路径、图层开关、视角复位、缩放与全屏。
- 全局空间与以小车为中心 3.2 m 范围的局部点云切换。局部视图是世界坐标中的附近点云，不冒充相机 RGB 视频或第一人称深度图。
- 类别/别名检索、多实例候选选择、物品详情、未知目标提示；新任务需要已定位、连接有效且无活动任务。
- 演示状态机、暂停/继续/取消；任务结束后本机记录，标注演示或实车来源。
- WebSocket 适配器：版本与结构校验、消息大小限制、序号去重、回执关联、超时、断线、过期状态、实时/演示隔离。
- 断线或数据超过 5 秒未更新后禁用新任务、弱化历史地图、显示位置/状态未知。网页不会伪造已停止的实车状态，不自动重发控制请求。
- 应用图标、manifest、离线应用壳；无需图片生成即可运行。

## 尚需团队完成

1. 实现 [M8 WebSocket v1 桥接接口](docs/protocol.md)，绑定 M4 物体记忆与点云、M2 位姿、M6 路径、M5 任务状态。本文定义的是本前端接入契约，不是团队已发布的 ROS 接口。
2. 确认坐标系、地图版本、服务器时间同步、真实目标类别、暂停语义、失败原因和取消后的状态反馈。
3. 实车端负责停靠点选择、可达性、避障、物体重新确认和底盘安全。M8 不实现导航算法，不向底盘直接发送速度。
4. 部署 HTTPS/WSS 和认证，确认多客户端任务互斥与命令幂等；完成真机断线、取消、未知目标、物体移位等验收。
5. 验证大规模点云带宽与性能；当前 JSON 每帧最多 60,000 点，建议桥接端降采样并低频发布。需要更大规模时应单独设计二进制点云通道。

“停止任务”是软件取消请求，不能替代硬件急停。回执 accepted 只表示受理，实际状态取决于后续快照。断线无法保证命令送达。

## 结构与验证

- `src/app.js`：页面与状态绑定；`src/model.js`：数据校验和控制条件。
- `src/scene.js`：使用 Three.js 渲染；`src/demo.js`：明确隔离的模拟源。
- `src/transport.js`：WebSocket 客户端；`server.mjs`：本地只读静态服务。
- `tests/model.test.mjs`：可用 `npm test` 运行的协议与状态测试。
- `tests/browser.cjs`：Playwright 端到端测试。默认使用本机 Codex 捆绑 Playwright 与 Edge，可通过 `PLAYWRIGHT_MODULE` / `BROWSER_PATH` 更改。
- `tests/design-audit.cjs` / `tests/motion.cjs`：当前玻璃界面的布局、操作状态与动画中断检查；最新截图在 `artifacts/glass/`。
- `tests/transitions.cjs`：实际鼠标在过渡期间连续导航、移动选中层、按钮按压、弹窗退场与动画兼容回退。
- `artifacts/`：浏览器验证截图；[验证记录](docs/VALIDATION.md)。

Three.js 0.180.0 及 OrbitControls 来自 jsDelivr 上的 three 官方 npm 包，已保存 MIT 许可证 `vendor/THREE-LICENSE.txt`。SVG 界面图标、演示模型由本项目代码绘制，不是 imagegen 生成素材。
